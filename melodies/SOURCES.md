# Источники мелодий

## bach-fugue.json — И. С. Бах, Фуга соль минор BWV 578 («Маленькая»)
- Композиция: общественное достояние.
- Кодировка: MIDI-файл Pierre Gouin, Les Éditions Outremontaises (Montréal, 2017), IMSLP #491939
  (https://imslp.org/wiki/Fugue_in_G_minor,_BWV_578_(Bach,_Johann_Sebastian)).
- Лицензия: Creative Commons Attribution-ShareAlike 4.0 (https://creativecommons.org/licenses/by-sa/4.0/).
- Изменения: конвертировано в JSON «Пузя Piano» (все 2400 нот, мануалы + педаль), время в долях при 88 BPM
  с сохранением темповых изменений оригинала; одна нота педали ниже C1 поднята на октаву.
  Этот производный файл распространяется под той же лицензией CC BY-SA 4.0.

## handel-halvorsen-passacaglia.json — Г. Ф. Гендель, Пассакалия из Сюиты № 7 соль минор, HWV 432 (оригинал для клавесина)
- Это оригинал Генделя, на котором основана Пассакалия Хальворсена (1894). Чистого MIDI/MusicXML версии Хальворсена
  в свободном доступе не нашлось, а распознанный скан давал много ошибок, поэтому черновик заменён.
- Композиция: общественное достояние.
- Кодировка: MIDI-файл Pierre Gouin, Les Éditions Outremontaises (Montréal, 2015), IMSLP #365892
  (https://imslp.org/wiki/Suite_in_G_minor,_HWV_432_(Handel,_George_Frideric)).
- Лицензия: Creative Commons Attribution-ShareAlike 4.0 (https://creativecommons.org/licenses/by-sa/4.0/).
- Изменения: конвертировано в JSON «Пузя Piano» (все 2520 нот), время в долях при 120 BPM. Длительность ≈ 4:11.
  Этот производный файл распространяется под той же лицензией CC BY-SA 4.0.

## bach-toccata-fugue.json — И. С. Бах, Токката и фуга ре минор BWV 565 (целиком)
- Композиция: общественное достояние.
- Кодировка: MIDI Mutopia Project #1780 (Mutopia-2011/09/11-1780), по изданию Bach-Gesellschaft Ausgabe, 1867
  (https://www.mutopiaproject.org/cgibin/piece-info.cgi?id=1780).
- Лицензия: Public Domain (https://creativecommons.org/licenses/publicdomain).
- Изменения: конвертировано в JSON «Пузя Piano» (3651 нота, мануалы + педаль), время в долях при 80 BPM
  с сохранением темповых изменений оригинала. Длительность ≈ 9:32.
